**Cotes** — это минималистичный редактор заметок, который хранит данные исключительно на вашем устройстве. Никаких подписок, аккаунтов и отправки ваших данных на чужие сервера. Просто открыл — и начал писать.

# 🚀 Возможности

- 📝 Список и редактор на одном экране, на телефоне — по очереди.
- 💾 Автосохранение: кнопки «Сохранить» больше нет, текст записывается, пока вы печатаете.
- 🔍 Мгновенный поиск по заголовкам и тексту с подсветкой совпадений.
- 📌 Закрепление важных заметок, сортировка по дате изменения.
- ↩️ Удаление с кнопкой «Отменить».
- 🌙 Светлая и тёмная тема (или как в системе).
- 📦 Резервная копия всех заметок в файл и восстановление из него, выгрузка заметки в .txt.
- ⌨️ Горячие клавиши: Alt+N — новая заметка, Ctrl/⌘+K — поиск, Ctrl/⌘+\ — скрыть список.
- 🔒 Приватность: заметки хранятся только в localStorage вашего браузера, приложение не делает ни одного внешнего запроса.

# Установка
1) Скачайте файлы проекта: **git clone https://github.com/dantemorrigan/Cotes.git**

2) Откройте index.html в браузере — и всё!
