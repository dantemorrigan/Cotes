**Cotes** — минималистичные заметки для Android. Хранятся на вашем телефоне, а если захотите — синхронизируются между вашими устройствами через ваш собственный Google Drive. Никаких подписок, рекламы и серверов разработчика. Открыл — и пишешь.

_Cotes is a minimal notes app for Android that keeps your notes on your phone — or, if you sign in with Google, syncs them through your own Google Drive. No tracking. Available in English and Russian._

# 📲 Установка

Последняя версия — во вкладке [Releases](https://github.com/dantemorrigan/Cotes/releases): скачайте `Cotes-X.Y.Z.apk`, откройте его на телефоне и разрешите установку из этого источника. Нужен Android 8.0 или новее. Новые версии ставятся поверх старых, заметки сохраняются.

**Переход с версий до 1.0.** Начиная с 1.0 приложение подписано новым ключом, поэтому поверх старой версии оно не встанет:
1. В старой версии: Настройки → «Резервная копия всех заметок».
2. Удалите старую версию и установите 1.0.
3. В 1.0: Settings → «Restore from backup» / Настройки → «Восстановить из копии».

Тестовые сборки из ветки `main` — в [Actions → Android build](https://github.com/dantemorrigan/Cotes/actions/workflows/android.yml), архив `Cotes-android-N`.

# 🚀 Возможности

- 💾 **Автосохранение.** Кнопки «Сохранить» нет: текст записывается, пока вы печатаете.
- ✍️ **Лёгкий Markdown:** заголовки, жирный, курсив, зачёркнутый, код, цитаты и выноски, списки подсвечиваются прямо в редакторе; заметка открывается для чтения — оформленный текст без значков; карандаш (или нажатие на текст) включает правку, где разметка видна бледной. Сам текст остаётся обычным Markdown. Нажатие на ☐ / `[ ]` отмечает пункт, Enter продолжает список, курсор в ссылке — кнопка «Открыть ссылку». В списке заметок превью без разметки, `[[ссылки]]` из Obsidian подсвечиваются.
- 🔍 **Мгновенный поиск** по заголовкам и тексту с подсветкой совпадений.
- 👆 **Свайпы:** вправо — закрепить заметку наверху, влево — удалить. Строка тянется «резиново» и срабатывает только при уверенном движении; удаление нужно подтвердить, а потом его можно отменить.
- ☑️ **Выбор нескольких заметок** — удержание заметки или кнопка «Выбрать»; «Выбрать все» и удаление разом.
- 📤 **«Поделиться»** заметкой в любое приложение; текст из другого приложения становится новой заметкой.
- ➕ **Ярлык «Новая заметка»** — долгое нажатие на иконку приложения.
- 📥 **Переезд из других приложений:** Simplenote (`.zip` или `notes.json`), Google Keep (архив Google Takeout или `.json`), Evernote (`.enex`), Standard Notes (расшифрованная копия), Obsidian, Joplin, Bear, Markor и любые `.md`/`.txt`, в том числе в `.zip`. Можно выбрать несколько файлов сразу; дубликаты и заметки из корзины пропускаются, теги становятся `#тегами`. Подсказка, где искать экспорт, — в настройках.
- 📤 **Экспорт в Markdown** — `.zip`, по файлу `.md` на заметку, для Obsidian, Joplin и других приложений.
- 📦 **Резервная копия** всех заметок в файл `.json` и восстановление из него.
- 🌍 **Английский и русский**, переключатель языка в настройках (на Android 13+ — и в системных настройках приложения).
- 👋 **Подсказки при первом запуске** — три коротких шага, только для новых пользователей.
- ⚙️ **Оформление:** системная, светлая или тёмная тема, чёрный фон для AMOLED, пять цветов акцента или цвета обоев (Material You), размер текста, компактный список.
- 📐 **Планшеты и альбомная ориентация:** список и заметка рядом.
- ☁️ **Синхронизация (по желанию).** При первом запуске — выбор: «Войти через Google» или «Только на этом устройстве»; войти или выйти можно и потом, в настройках (раздел «Аккаунт» с профилем и состоянием синхронизации).
  - Заметки хранятся в скрытой папке приложения в вашем Google Drive и появляются на всех Android-устройствах, где вы вошли. Остальные файлы Drive приложение не видит.
  - Синхронизация идёт сама: при открытии, через пару секунд после правки, раз в минуту, пока приложение открыто, и при сворачивании. Сразу — жестом «потянуть список вниз».
  - Правки, закрепление и удаление доходят до всех устройств; если одну заметку правили на двух устройствах одновременно, сохраняются обе версии.
  - При первом входе заметки с телефона и из облака объединяются — ничего не удаляется. Выход из аккаунта оставляет заметки на устройстве.
- 🔒 **Приватность:** без входа приложение не выходит в интернет; заметки не попадают ни в облачный бэкап Android, ни в перенос на новый телефон, а разработчику — никогда. Подробно — в [PRIVACY.md](PRIVACY.md).
- 🔔 **Звуки действий:** мягкие короткие звуки при создании, закреплении и удалении заметок, отмене удаления, входе и ручной синхронизации. Набор текста и навигация беззвучны, в беззвучном режиме телефона звуков нет; выключаются в настройках.
- 🛟 **Надёжность:** если файл заметок повреждён, Cotes не перезаписывает его, а предлагает сохранить копию.

# 🛠 Для разработчиков

```
android/                    приложение: Kotlin, Jetpack Compose, Material 3
  app/src/main/             код и ресурсы (тексты — res/values и res/values-ru)
  app/src/test/             юнит-тесты (JVM)
  app/src/androidTest/      сценарные тесты на эмуляторе
  scripts/regress.sh        прогон тестов на эмуляторе: en/ru × светлая/тёмная
  scripts/check-strings.sh  проверка, что в коде нет «зашитых» русских строк
  release.keystore.enc      ключ подписи, зашифрованный паролем из секрета
fastlane/metadata/android/  тексты, иконка и скриншоты для магазинов
docs/STORES.md              как публиковать в Google Play, RuStore, F-Droid
```

Текущая версия — **1.2.1**.

Сборка: `cd android && ./gradlew assembleDebug` (JDK 17, Android SDK 37). Проверки, как в CI: `./scripts/check-strings.sh && ./gradlew testDebugUnitTest lintRelease`.

**Тексты интерфейса** — только в `res/values/strings.xml` (английский, по умолчанию) и `res/values-ru/strings.xml`. Lint не пропустит строку без перевода, а `check-strings.sh` — русский текст прямо в коде.

**CI.** При каждом изменении в `android/` GitHub Actions запускает юнит-тесты и lint, собирает подписанный APK и прогоняет сценарии на эмуляторе Android 14 на двух языках в двух темах. Скриншоты публикуются в ветку `ci/android-screens`.

**Версии.** `versionCode` — число коммитов, `versionName` берётся из тега `vX.Y.Z` (между релизами — `X.Y.Z-dev.N`).

**Релиз.** Actions → `Release` → Run workflow, версия `X.Y.Z` (или `git push origin vX.Y.Z`). Workflow создаст тег, соберёт APK и AAB, проверит подпись и опубликует GitHub Release с заметками из `fastlane/metadata/android/*/changelogs/` (`<versionCode>.txt`, иначе `default.txt`).

**Вход через Google.** Ключей в коде нет: Google узнаёт приложение по имени пакета и отпечатку подписи. В Google Cloud (проект Cotes) включён Drive API, на экране согласия (Google Auth Platform) — только область `drive.appdata`, статус «In production», и создан OAuth-клиент Android: пакет `io.github.dantemorrigan.cotes` + SHA-1 релизного ключа (его печатает CI в шаге «Signing certificate fingerprint»). Сборки, подписанные другим ключом, войти не смогут. Синхронизация — `android/app/src/main/java/.../sync/`: `SyncMerge` (слияние, покрыто юнит-тестами), `DriveApi` (REST Drive), `SyncManager` (когда и как синхронизировать).

**Ключ подписи** хранится в репозитории только в зашифрованном виде (`android/release.keystore.enc`, AES-256), пароль — в секрете `RELEASE_KEYSTORE_PASSWORD`. Без пароля сборка подписывается отладочным ключом. Отпечаток сертификата — в `android/release-cert-sha256.txt`. Потеря пароля означает, что выпускать обновления поверх установленной версии будет нельзя.
