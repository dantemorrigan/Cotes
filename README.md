**Cotes** — минималистичные заметки для Android, которые хранятся только на вашем телефоне. Никаких подписок, аккаунтов и отправки данных на чужие серверы. Открыл — и пишешь.

# 📲 Установка

1. Откройте вкладку [Actions → Android build](https://github.com/dantemorrigan/Cotes/actions/workflows/android.yml) и выберите последний успешный запуск из ветки `main`.
2. Внизу страницы скачайте архив `Cotes-android-N` и распакуйте его — внутри файл `Cotes-N.apk`.
3. Откройте APK на телефоне и разрешите установку из этого источника.

Нужен Android 8.0 или новее. Новые версии ставятся поверх старых, заметки сохраняются.

# 🚀 Возможности

- 💾 **Автосохранение.** Кнопки «Сохранить» нет: текст записывается, пока вы печатаете, а внизу видно «✓ Сохранено».
- 🔍 **Мгновенный поиск** по заголовкам и тексту с подсветкой совпадений.
- 👆 **Свайпы:** вправо — закрепить заметку наверху, влево — удалить.
- ↩️ **«Отменить»** после удаления — случайно стёртая заметка возвращается одним нажатием.
- 📤 **«Поделиться»** заметкой в любое приложение, а текст, которым поделились из другого приложения, сразу становится новой заметкой.
- 📦 **Резервная копия** всех заметок в файл `.json` и восстановление из него.
- ⚙️ **Настройки оформления:** тема (системная, светлая, тёмная), чёрный фон для AMOLED, пять цветов акцента или цвета обоев (Material You), размер и шрифт текста в редакторе, компактный список. Всё меняется сразу и плавно.
- 🌙 **Светлая и тёмная тема**, иконка поддерживает тематические иконки Android 13+.
- 📐 **Планшеты:** список и заметка рядом на одном экране.
- 🔒 **Приватность:** у приложения нет разрешения на интернет, заметки лежат только в его памяти на устройстве.

# 🌐 Веб-версия

Простая версия для браузера доступна на [dantemorrigan.github.io/Cotes](https://dantemorrigan.github.io/Cotes/) — или откройте `index.html` из репозитория. Заметки хранятся в браузере.

Перенести заметки между телефоном и браузером можно через резервную копию: «Резервная копия всех (.json)» в одной версии и «Восстановить из копии…» в другой — формат у них общий.

# 🛠 Для разработчиков

```
android/            приложение: Kotlin, Jetpack Compose, Material 3
  app/src/main/     код и ресурсы
  app/src/androidTest/  сценарные тесты
  scripts/regress.sh    прогон тестов на эмуляторе
index.html, notes-and-edit.html, assets/   веб-версия
```

Сборка: `cd android && ./gradlew assembleRelease` (нужны JDK 17 и Android SDK).

При каждом изменении в `android/` GitHub Actions собирает APK и прогоняет тесты на эмуляторе Android 14 в светлой и тёмной теме, а также проверяет, что релизная сборка запускается. Скриншоты прогона публикуются в ветку `ci/android-screens`.

APK подписан ключом из репозитория (`android/app/cotes-debug.keystore`), чтобы обновления ставились поверх. Для публикации в Google Play нужен собственный закрытый ключ.
