# Публикация в магазинах

Всё, что можно подготовить заранее, лежит в репозитории:

| Что | Где |
|---|---|
| Название, короткое и полное описание (en, ru) | `fastlane/metadata/android/<язык>/*.txt` |
| Что нового в версии | `fastlane/metadata/android/<язык>/changelogs/` |
| Иконка 512×512, баннер 1024×500 | `fastlane/metadata/android/<язык>/images/` |
| Скриншоты телефона | `fastlane/metadata/android/<язык>/images/phoneScreenshots/` |
| Политика конфиденциальности | `PRIVACY.md` (нужна публичная ссылка, см. ниже) |
| Сборки | GitHub Release `vX.Y.Z`: `Cotes-X.Y.Z.apk`, `Cotes-X.Y.Z.aab` |
| Отпечаток ключа подписи | `android/release-cert-sha256.txt` |

Формат папки `fastlane/` понимают F-Droid, IzzyOnDroid и `fastlane supply` для Google Play.
В RuStore и Google Play тексты и картинки можно вставить вручную из этих файлов.

## Общие ответы для анкет

- **Категория:** Productivity / «Продуктивность» (в RuStore — «Инструменты» → «Заметки», если есть).
- **Возрастной рейтинг:** 3+ / 0+. Нет насилия, азартных игр, покупок, общения между пользователями, рекламы.
- **Реклама:** нет. **Платные функции:** нет. **Аккаунт для проверки:** не нужен.
- **Разрешения:** никаких опасных разрешений; интернет — только для синхронизации с Google Drive после входа.
- **Целевая аудитория:** 13+ (можно и «все возрасты»: данных никто не собирает).

## Google Play

1. Аккаунт разработчика Google Play (разовый взнос). Для новых личных аккаунтов Google требует
   закрытое тестирование с несколькими тестировщиками в течение двух недель перед публикацией —
   проверь актуальные условия в Play Console.
2. Загружается **AAB** (`Cotes-X.Y.Z.aab`). Включи Play App Signing и загрузи наш ключ как ключ загрузки
   (upload key) — Play Console подскажет шаги; отпечаток для сверки в `android/release-cert-sha256.txt`.
3. **Data safety:** «Приложение не собирает и не передаёт пользовательские данные» (No data collected, No data shared).
   Шифрование при передаче — неприменимо (нет сети). Удаление данных — через удаление приложения.
4. **Privacy policy URL** — обязательна (см. «Публичная ссылка на политику»).
5. **Content rating** — анкета IARC, ответы «нет» на все пункты; категория Utility/Productivity.
6. **Target API** — 36 (Android 16), требование Play выполнено.

## RuStore

1. Аккаунт разработчика RuStore (физлицо, самозанятый, ИП или юрлицо).
2. Загружается APK или AAB. RuStore просит подписывать обновления тем же ключом —
   используем `Cotes-X.Y.Z.apk` из GitHub Release.
3. Тексты — из `fastlane/metadata/android/ru-RU/`, скриншоты — оттуда же; нужна ссылка на политику конфиденциальности.

## F-Droid и IzzyOnDroid

Оба требуют **открытого исходного кода и публичного репозитория** (F-Droid сам собирает приложение
из исходников, IzzyOnDroid берёт APK из публичных GitHub Releases).
Пока репозиторий приватный, эти каталоги недоступны. Если решишь открыть код:
1. Добавить файл лицензии (например, GPL-3.0 или MIT) — сейчас лицензии нет.
2. Сделать репозиторий публичным; метаданные `fastlane/` уже на месте.
3. IzzyOnDroid: заявка в их репозитории на GitLab со ссылкой на GitHub Releases.
   F-Droid: merge request в `fdroiddata` (сборка из исходников; для подписи нашим ключом
   нужна воспроизводимая сборка — можно начать с подписи ключом F-Droid).

## Публичная ссылка на политику

Магазинам нужна открытая ссылка, а репозиторий приватный (GitHub Pages для приватных
репозиториев доступен только на платных тарифах). Варианты:
- маленький **публичный** репозиторий только с `PRIVACY.md` и включёнными GitHub Pages;
- любая страница, которую ты контролируешь (сайт, Notion, Google Sites) с текстом из `PRIVACY.md`.

Готовая страница с политикой на двух языках лежит в `docs/privacy/index.html` (собрана из `PRIVACY.md`, адрес поддержки уже вписан).
Чтобы получить ссылку: создай публичный репозиторий, положи туда этот файл как `index.html`, включи GitHub Pages
(Settings → Pages → Deploy from a branch → main / root) — ссылка будет вида `https://<логин>.github.io/<репозиторий>/`.
После правок `PRIVACY.md` страницу нужно пересобрать и загрузить заново.
