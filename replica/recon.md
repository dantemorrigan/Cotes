# Recon: Cotes и практики простых редакторов заметок

Цель: не клон, а улучшение собственного приложения Cotes. Берём у известных
редакторов заметок только UX-паттерны (как устроен поток работы), а не их
код, тексты или ассеты. Иконка Cotes (`assets/images/logo.svg`,
`favicon.png`, `logo.png`) остаётся без изменений.

## 1. Scope

| вопрос | ответ |
| --- | --- |
| приложение | Cotes, веб, статические HTML/CSS/JS, данные в `localStorage` |
| срез | основной цикл: открыть → написать → найти → удалить/вернуть |
| для кого | человек, которому нужен приватный блокнот без аккаунта и сервера |
| ограничения | работает с `file://` (README: «откройте index.html»), без сборки, без сети |

## 4. Потоки

```
F01 Написать новую заметку
    S01 → S02 «Новая» (или Alt+N) → печатать → автосохранение
    было: 4 действия (кнопка, заголовок, текст, «Сохранить»); цель: 2
    edge: пустая заметка не сохраняется; закрытие вкладки во время ввода
F02 Найти заметку
    S02 поиск (Ctrl+K или /) → ввод → клик по результату
    edge: ничего не найдено; заметка без заголовка; Esc очищает
F03 Удалить и передумать
    S02 корзина → тост «Удалено · Отменить» → отмена возвращает
    было: 2 клика + модалка, без возврата
F04 Закрепить важное
    S02 «Закрепить» → заметка сверху списка
F05 Резервная копия
    S02 меню → «Экспорт» (JSON всех заметок / .txt текущей) → «Импорт»
F06 Продолжить работу
    открыть S02 → открыта последняя заметка, список по дате изменения
```

## 5. Компоненты

| компонент | варианты | экраны |
| --- | --- | --- |
| кнопка | primary, ghost, icon, danger | S01, S02 |
| поле поиска | пусто, ввод, с крестиком | S02 |
| элемент списка | обычный, активный, закреплён, с подсветкой совпадения | S02 |
| редактор | заголовок + текст, плейсхолдеры | S02 |
| строка статуса | «Сохранено», дата изменения, слова/символы | S02 |
| тост | информ., с действием «Отменить» | S02 |
| пустое состояние | нет заметок, нет результатов, не выбрано | S02 |
| переключатель темы | системная / светлая / тёмная | S01, S02 |

## 6. Модель данных

```
Note  id (string), title, content, created (ms), updated (ms), pinned (bool)
      evidence: текущий формат {title, content} в localStorage['notes']
      миграция: старым записям выдаётся id и created=updated=сейчас; ключ тот же
      confidence: high
Prefs theme (system|light|dark), lastOpenId — localStorage['cotes:prefs']
```

## 8. Что не делаем

- Синхронизация между устройствами и аккаунты: противоречит идее Cotes (всё локально).
- Markdown-рендер, вложения, теги — не входит в быстрый объём; можно позже.
- Service worker / PWA: не работает при открытии с `file://`, как описано в README.

## 9. Размер

3 экрана, 6 потоков, 1 сущность. Сложные места: сохранение без потерь
(автосохранение + `pagehide` + синхронизация вкладок), миграция старых
заметок, мобильная одно-панельная навигация. Размер: **S**.
